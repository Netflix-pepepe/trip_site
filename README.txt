人狼オンライン データベース - 設定不要版

このZIPは「サイト側でAPI URLを設定する」操作をなくした版です。

使い方:
1. PHP + SQLite + cURL が使えるWebサーバーへ、このフォルダの中身をそのまま配置。
2. index.php を開く。
3. API URL・APIキーの入力は不要。
4. 個人戦績は「名前/トリップ」で検索すると backend/api.php が公開ログ検索APIへ接続して取得します。
5. ランキングはDBが空なら最初のランキング取得時に自動同期を試みます。
6. 継続更新は backend/cron.php をサーバーのcron等から実行できます。

注意:
GitHub PagesのようなPHPを実行できない静的ホスティングだけでは、サーバー側自動取得は実行できません。
この版はPHPサーバーへ「置くだけ」にすることを目的にしています。
